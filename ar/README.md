# Arabic RTL (`/ar/`)

True RTL Arabic site shell for Imperial Solution Company.

## Rules

- `lang="ar"` `dir="rtl"`
- **Noto Sans Arabic** via `css/main.css` (preconnect on AR pages)
- Mirroring via logical CSS + `css/rtl.css` + `js/rtl.js`
- Language switch: `EN | العربية` → `/page.html` ↔ `/ar/page.html`
- hreflang: `en`, `ar`, `x-default` (English)

## Content

Do not invent Arabic marketing copy. Use:

`[ARABIC CONTENT TO BE PROVIDED]`

UI chrome (nav, CTAs, form labels) may use short provisional Arabic for RTL testing until an approved glossary is supplied.

## Pages

All English marketing/form pages have an `ar/` equivalent.
