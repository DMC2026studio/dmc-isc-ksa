How references are labelled

A partner reference is not an ISC project. Every entry carries an explicit type so visitors never confuse partner capability with ISC delivery history.

Partner reference

Work completed by or under a technology partner. Published only with partner approval and clear attribution. Active type for this library.

ISC project

Reserved for future ISC delivery. Same library, separate type tag — added only when ISC has its own confirmed portfolio.
